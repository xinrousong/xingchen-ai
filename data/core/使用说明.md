# 星辰记忆系统 · 小白使用说明

> 这份文件教你怎么给星辰"注入永不忘记的记忆"。全程只有三件事要做：
> **写宪法、写故事、写问答**，然后按一条命令。不需要懂任何原理。

## 一、这套系统是什么（三个比喻）

| 东西 | 比喻 | 存放位置 |
|---|---|---|
| 宪法 constitution.txt | 她的**出厂性格**：她是谁、你希望她相信什么、她怎么说话 | `data/core/constitution.txt` |
| 故事 stories/*.txt | 她的**人生经历**：你写给她的每一个故事，一辈子累积 | `data/core/stories/` |
| 问答 qa/*.jsonl | **理解的考试题**：她光"读过"故事不算懂，能答对题才算懂 | `data/core/qa/` |

原理一句话：模型没有"记忆区"，她记得的一切都来自训练时反复读到的文字。
这套系统做的事就是——**每次训练都把这些文件喂给她，重复足够多遍**。
流水线已经替你做好这个"每次都喂"，你只管写内容。

## 二、你只需要做的三件事

### 第 1 件：写宪法

打开 `data/core/constitution.txt`（已经有一份带【示例】的模板），
把【示例】段落换成你自己的话。不用管格式，写大白话就行。
建议 300～1500 字：太短立不住，太长会占太多训练量。

### 第 2 件：写故事

在 `data/core/stories/` 里新建 `.txt` 文件，**一个故事一个文件**，
文件名就是故事名（如 `我的第一个故事.txt`）。想写多少篇写多少篇。

### 第 3 件：写问答

每写完一个故事，顺手出几道题。在 `data/core/qa/` 里新建 `.jsonl`
文件，**每行一条**，格式照抄下面（三行示范，直接复制改内容）：

```
{"q": "故事里的主角叫什么？", "a": "主角叫阿澄。", "keywords": ["阿澄"]}
{"q": "故事的结尾说明了什么？", "a": "灯不问有没有船，灯只管亮着。", "keywords": ["灯不问"]}
{"q": "你读完这个故事有什么感觉？", "a": "我觉得坚持本身就有意义。", "keywords": []}
```

- `q` 是问题，`a` 是你希望她答出的样子
- `keywords` 是"判卷关键词"：她的回答里出现其中任意一个词就算答对
  （写人名、地名、关键短语这种**答案里一定会出现的词**；开放感受题就留空 `[]`）

## 三、一键训练（让她把记忆吃进去）

写完内容后，在 Git Bash 里执行两行：

```bash
cd /d/dsh-demo/xingchen
/d/dsh-demo/ComfyUI_windows_portable/python_embeded/python.exe scripts/auto_train.py --fresh
```

`--fresh` 的意思是"她该学新记忆了"：流水线会自动做五件事——
语料加工（把宪法和故事掺进 3 亿 token 里，重复约 20 遍）→ 续训预训练
（约 2.5 小时）→ 用宪法问答做对话微调（约 20 分钟）→ **自动考试** → 报告。

安全无需操心：看门狗全程值守（≥80°C 自动暂停散热，≥90°C 强终止），
电源已设置不睡眠。中途断了就重跑同一条命令，会自动接着来。

## 四、看成绩单

```bash
/d/dsh-demo/ComfyUI_windows_portable/python_embeded/python.exe scripts/core_check.py
```

- `✅` = 答对（回答里出现了你的关键词）——记忆在
- `❌` = 答错——这条还没学会（正常，理解是一批一批训练慢慢加深的）
- 报告同时存在 `logs/core_check.log`，每次成绩都会留档，能看出她在成长

## 五、什么时候"懂"（诚实的预期）

- 第一轮训练后：她能复述宪法和故事的大意（✅ 会开始出现）
- 三五轮后：情节题、人物题基本都能答对，说话带你的故事的味儿
- 但要记住她只有 5700 万参数：她能**记住并简单运用**你的故事，
  深层的隐喻和长线推理要等以后换更大的模型（同一套 core 文件直接带走，记忆不失）

## 六、三条红线

1. **隐私别写**：写进宪法/故事的内容会被她"背进本能"，将来可能被复述出来。密码、住址别放
2. **分词器别动**：`data/wiki/tokenizer.json` 不要重新生成——一换，她全部旧记忆作废
3. **别只训一次**：记忆靠反复强化，隔一阵子就把 `--fresh` 跑一遍（或加新故事时顺手跑）

## 七、常见问题

**Q：改了宪法，旧的记忆会丢吗？**
不会丢，会"换"。她记住的是最近一次训练时喂的内容；你改掉的部分被新写法覆盖，没改的部分继续在。

**Q：故事写多长合适？**
几十到几千字都行。太长（几万字）建议拆成几个文件。

**Q：训练期间能用电脑吗？**
能，但别开 ComfyUI（会抢显存）。刷网页、写文档没问题。

**Q：怎么知道流水线跑到哪了？**
看 `logs/pipeline.log`（总进度）和浏览器面板 `http://127.0.0.1:8765`（温度和曲线）。

**Q：我想推倒重来怎么办？**
删掉 `data/core/` 里你不想要的内容，然后 `auto_train.py --fresh`。
她没有藏在你看不到的地方的记忆——**她记得的一切，就是 core 目录 + 语料库**。
